Self-Indexing Beach

One wave port. Thirty-six sand-controlled links. Four listening ports. Write a storm into the medium, then send a weak, nonwriting ping. Map the index to see which patches of sand influence that particular answer. Change the query frequency or phase: the address map changes even when the bed does not.
